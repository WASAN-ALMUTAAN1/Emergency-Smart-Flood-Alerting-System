Smart Flooding Detection System
AI Analysis Flood Detection Computer Vision Risk Monitoring

This platform uses advanced computer vision models to analyze flood scenarios from images. The Classification model determines whether flooding is present, the Detection model identifies humans and vehicles in the scene, and the Segmentation model highlights flooded areas and estimates water levels around each person, classifying them into twelve distinct levels. Users can upload an image and select a model for analysis. The dashboard then presents clear results, including flood classification, detected objects, and segmentation overlays that visualize flooded regions and estimated water levels.
